⚖️ Decision Engine Framework

"The Neural Network assists incident classification, while LifeLine combines ML predictions with infrastructure evidence, student impact, and safety rules to make operational decisions."

1. Neural Network Input (25%)

TF-IDF text vector + one-hot category into Multi-Layer Perceptron (MLP) producing Softmax probabilities.

2. Service Criticality (25%)

Asset Tier scoring: Website/Portal/Water (Tier 5), LMS/Hostel Network (Tier 4), Single Room (Tier 2).

3. Student Impact (20%)

Headcount scaling: 4,000+ campus users vs. 450 hostel residents vs. single room.

4. Safety & Telemetry (30%)

Physical fire/spark/health hazards + live DOWN status + multi-student report clusters.
